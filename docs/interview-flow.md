# Interview Flow

## 轮次

- 技术一面：基础、项目基础、系统设计入门。
- 技术二面：复杂项目、架构、高并发和稳定性。
- 技术三面：技术负责人、管理、决策和业务战略。
- HR 面：动机、协作、规划、抗压和薪资。

## 状态机

```text
轮次
  → 当前阶段
    → 当前主问题
      → 主问题回答
        → 是否追问？
          → 是：追问，未达到上限继续追问
          → 否：进入下一主问题
      → 主问题全部完成
    → 进入下一阶段
  → 所有阶段完成
  → 生成复盘和记录
```

## 追问规则

- 每个主问题配置最大追问次数。
- 长回答且未出现“不知道 / 没做过 / 跳过 / 不了解 / 不会”时允许追问。
- 追问必须引用候选人回答，并保持当前阶段边界。
- 达到追问上限后进入下一主问题。
- 问题与上一题高度相似时触发重写或兜底追问。

## 输入模式

- 语音输入：浏览器录音 → ASR → 候选人文案。
- 文字输入：文本框 → 候选人文案。
- 两种模式共用同一套状态机和复盘逻辑。

## 输出

- JSON：结构化会话数据。
- Markdown：可阅读的完整面试记录。
- 弱项标签：用于下一次训练的薄弱点统计。
